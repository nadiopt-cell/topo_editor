# TopoPolyEdit — топологическое редактирование полигонов для QGIS

Модуль для QGIS 3.10+ (включая LTR 3.34 и новее, Qt5/Qt6), реализующий
топологическое редактирование полигональных слоёв.

**Главный принцип: изменяется ТОЛЬКО редактируемый слой.** Все остальные
слои используются только как эталоны — для прилипания и для отсечения
перехлестов. Никакие данные соседних слоёв не модифицируются.

## Возможности

| Функция | Как работает |
|---|---|
| Перемещение общих узлов | Перетаскиваете узел — он смещается сразу во **всех полигонах редактируемого слоя**, где этот узел есть (по допуску прилипания) |
| Прилипание (snapping) | К узлам и рёбрам **всех включенных (отмеченных в легенде) слоёв** в текущем экстенте карты + к самому редактируемому слою. Радиус — 10 px. Приоритет: узел > ребро |
| Автоотсечение перехлестов | Если после подтягивания полигоны наложились на соседей — перехлест автоматически отсекается (`difference`) по контуру эталонных полигонов |
| Вставка узла на ребро | Клик по ребру — узел вставляется во все полигоны слоя, содержащие это ребро, включая **T-образные примыкания** (когда граница соседа не имеет узла в этой точке) |
| Отмена | Все изменения одной операции — единая команда: **Ctrl+Z** откатывает перемещение/вставку целиком |

## Установка

1. Меню **Модули → Управление модулями… → Установить из ZIP**.
2. Выберите файл `topopolyedit.zip` → **Установить**.
3. Убедитесь, что модуль **TopoPolyEdit** включён в списке установленных.

Появится панель инструментов «Топологическое редактирование» (две кнопки),
а также пункты в меню **Вектор → Топологическое редактирование**.

## Быстрый старт

1. Загрузите полигональный слой (для проверки — `topopolyedit_test_data.geojson`
   с тремя соприкасающимися полигонами A, B, C) и включите его редактирование
   (карандаш). Слой должен быть активным.
2. Нажмите кнопку **«Топологическое перемещение узлов»** (иконка с оранжевым
   перекрестием на узле).
3. Наведите курсор на узел — он подсветится зелёным квадратом. Зажмите ЛКМ
   и тяните: оранжевые резиновые ленты покажут все полигоны, которые
   поедут вместе с узлом.
4. Отпустите кнопку: прилипание применится, перехлесты отсекутся,
   в панели сообщений появится сводка.
5. Кнопка **«Добавить узел на ребре»** (иконка с плюсом): наведите на ребро —
   оно подсветится оранжевым, кружок покажет точку вставки; клик — узел
   добавлен во все смежные полигоны.
6. **Esc** — отмена перетаскивания / выход из инструмента.

Проверка на тестовых данных: узел (2, 4) общий для полигонов A, B и C —
при его перетаскивании изменятся все три полигона; ребро x=2 (от y=0 до y=4)
общее для A и B — вставка узла на него произойдёт в обоих полигонах.

## Как это устроено внутри

* **Поиск общего узла.** По клику находится ближайшая вершина редактируемого
  слоя (допуск 10 px), затем все фичи слоя, содержащие вершину в этом
  допуске, — они образуют «набор перемещения».
* **Прилипание.** По каждому включенному слою выполняется запрос фич
  в экстенте вокруг курсора (с преобразованием CRS, если оно требуется).
  Сначала ищется ближайший узел, при промахе — ближайшее ребро (проекция).
  Перемещаемые фичи исключаются из прилипания, чтобы не «прилипать к себе».
* **Автоотсечение.** После перемещения каждая новая геометрия последовательно
  обрезается (`QgsGeometry.difference`) эталонными полигонами включенных
  слоёв (кроме перемещаемых фич). Полностью поглощённый полигон не
  изменяется (пропуск фиксируется в сообщении).
* **Атомарность.** Все `changeGeometry` одной операции обёрнуты в
  `beginEditCommand` / `endEditCommand` — единый шаг отмены.

## Ограничения и заметки

* Редактируемый слой должен быть **полигональным** и находиться **в режиме
  редактирования** (плагин предложит включить его автоматически).
* Поддерживаются 2D-геометрии (Z/M отбрасываются при записи), прямые
  сегменты; дуговые сегменты при записи сегментируются.
* Отсечение выполняется по полигонам **включенных** слоёв; если нужно
  отсекаться по какому-то слою — включите (отметьте) его в панели слоёв.
* Если граница соседа в *другом* слое не имеет узла в точке примыкания,
  после перемещения возможен зазор между слоями: плагин изменяет только
  редактируемый слой. Используйте инструмент «Добавить узел на ребре»
  на соседнем слое (сделав его редактируемым), чтобы швы совпадали.
* Внутри одного редактируемого слоя топология сохраняется автоматически:
  общие узлы двигаются вместе, общие рёбра получают вставки синхронно.

## Файлы плагина

```
topopolyedit/
├── metadata.txt            # метаданные модуля
├── __init__.py             # classFactory
├── plugin.py               # тулбар, меню, действия
├── utils.py                # выбор редактируемого слоя, допуски
├── geo_utils.py            # топологическая математика (2D)
├── snapping_engine.py      # прилипание ко всем включенным слоям
├── topo_editor.py          # перемещение узла + автоотсечение, вставка
├── topo_move_tool.py       # инструмент перемещения узлов
├── topo_add_vertex_tool.py # инструмент вставки узла на ребро
└── icons/*.svg             # иконки
```
