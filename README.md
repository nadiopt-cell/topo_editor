# topopolyedit — плагин QGIS для топологического редактирования полигонов

Модуль для QGIS 3.22+ (LTR 3.34/3.40+, Qt5/Qt6). Перемещайте узлы и целые рёбра —
смежные полигоны едут вместе с ними, прилипайте к выбранным слоям,
вставляйте узлы на общие рёбра; перехлесты отсекаются автоматически.

**Главный принцип: изменяется ТОЛЬКО редактируемый слой.** Остальные слои —
только эталоны для прилипанию и отсечения.

## Возможности

- **Перемещение общих узлов** — один узел двигается сразу во всех полигонах
  редактируемого слоя, где он есть (включая углы внешнего контура,
  принадлежащие одному полигону).
- **Перемещение целого ребра** — тянете общую границу: вся прямолинейная
  цепочка вершин (оба конца + промежуточные узлы) смещается параллельным
  переносом, все смежные полигоны двигаются сразу.
- **Прилипание** — к узлам и рёбрам включённых (отмеченных в легенде)
  слоёв — полигональных, линейных и точечных — в экстенте карты;
  «строгий» снэп к узлам: радиус узла 15 px против 10 px у ребра
  (настраивается), узел побеждает ребро, даже если ребро ближе.
- **Настройки прилипания** — диалог: галочками выбираются слои-эталоны
  (кому прилипаем, кому нет; кнопка «Обновить» перечитывает список слоёв),
  допуски к рёбрам и узлам задаются в пикселях экрана или единицах карты
  (с предупреждением, если радиус узлов меньше радиуса рёбер); действуют
  сразу, сохраняются между сеансами QGIS.
- **Автоотсечение перехлестов** — `difference` по эталонным полигонам
  включённых слоёв при отпускании кнопки.
- **Перехлёст с объектами того же слоя** — по запросу: область наезда
  подсвечивается красным прямо при перетаскивании, при отпускании кнопки
  спрашивается: обрезать перемещаемые полигоны / обрезать соседей /
  оставить перехлёст / отменить правку (в настройках можно выбрать
  «всегда обрезать» или «не обрезать»). Не зависит от настроек прилипания.
- **Подсветка вершин прилипания** — при перетаскивании узла и ребра:
  бирюзовые квадраты — вершины слоёв-эталонов рядом с курсором,
  фиолетовые кружки — все вершины объекта, к которому идёт прилипание;
  отключается в настройках.
- **Аудит слоя** — пакетный поиск ошибок всего слоя в фоне (QgsTask с
  прогрессом и отменой): невалидные геометрии, щели, перехлёсты, дубли
  вершин, почти совпавшие узлы, T-примыкания, шипы, сливеры; таблица с
  фильтром и переходом на место, экспорт в точечный слой,
  «Исправить все (безопасные)» — одной командой отмены, через валидатор,
  с контролем изменения площади;
- **Аудит узлов на границах слоёв** — кнопка-режим (работает поверх любого
  инструмента): узлы редактируемого слоя — **оранжевые квадраты**, узлы
  слоёв прилипания — **синие кружки**, одновременно в видимой области;
  **красные крестики** — узлы на чужой границе без пары на другой стороне
  (лишние или недостающие узлы — топологические ошибки на стыке слоёв);
  обновляется при пан/зуме и правках, состояние запоминается.
- **Вставка узла на ребро** — во все полигоны слоя с этим ребром,
  включая T-образные примыкания (защита от «шипов» и дубликатов узлов).
- **Журнал диагностики** — внутренние сбои (CRS, difference, превью)
  пишутся в панель «Журнал сообщений», вкладка «TopoPolyEdit».
- **Единая отмена** — каждая операция = одна команда Ctrl+Z.

## Установка в QGIS

1. Соберите архив (или возьмите готовый из релиза):
   ```
   python tools/make_zip.py        # -> dist/topopolyedit.zip
   ```
2. QGIS: **Модули → Управление модулями → Установить из ZIP** → `dist/topopolyedit.zip`.
3. Включите модуль **TopoPolyEdit**. Появится панель «Топологическое редактирование»
   и пункты в меню **Вектор**.

## Быстрый старт

1. Загрузите полигональный слой (например, `test_data/topopolyedit_test_data.geojson`)
   и включите редактирование.
2. Кнопка **«Топологическое перемещение узлов»**: наведите на узел (зелёный
   квадрат), зажмите ЛКМ, тяните — оранжевые ленты показывают все полигоны,
   которые поедут вместе с узлом. Отпустите — прилипание + отсечение.
3. Кнопка **«Перемещение ребра»**: граница подсветится оранжевой линией
   с квадратами на концах, тяните — красная линия показывает новое
   положение, оранжевые ленты — все смежные полигоны.
4. Кнопка **«Добавить узел на ребре»**: ребро подсветится оранжевым, клик —
   узел вставлен во все смежные полигоны.
5. **Подсветка прилипания** (при перетаскивании): бирюзовые квадраты —
   вершины слоёв-эталонов рядом с курсором; фиолетовые кружки — все
   вершины объекта, к которому происходит прилипание (видны даже без
   привязки — «куда целиться»); фиолетовая линия — ребро привязки.
6. **Аудит узлов**: включите кнопку — узлы обоих слоёв видны сразу;
   красные крестики вдоль общей границы показывают, где у соседа есть
   узел, а у вас нет (или наоборот).
7. **Esc** — отмена перетаскивания / выход из инструмента.

Проверка на тестовых данных: узел (2, 4) общий для полигонов A, B, C —
при перетаскивании изменятся все три; ребро x=2 общее для A и B — при
перемещении ребра сдвинется граница обоих полигонов.

Подробности (алгоритмы, ограничения) — в [topopolyedit/README.md](topopolyedit/README.md).

## История

### Что нового в 1.11.0

**Этап 5 ТЗ: аудит слоя — пакетный поиск ошибок и безопасное
исправление.** Новый инструмент «Аудит слоя…» рядом с «Аудитом узлов»:

* **восемь проверок** (по одной на класс в `core/checks/`, прогон —
  `QgsTask` в фоне с прогрессом и отменой): невалидные геометрии
  (INVALID), щели между полигонами (GAP, плиточный `unaryUnion` —
  бюджет не зависит от размера слоя), перехлёсты (OVERLAP), дубли
  подряд идущих вершин (DUP_NODE), почти совпавшие узлы разных
  полигонов (NEAR_NODE), T-примыкания без узла (T_JUNCTION), шипы
  (SPIKE), сливеры (SLIVER);
* **таблица результатов** — код, слой, fid, координаты, площадь,
  сообщение; фильтр по коду; двойной клик — переход на место с
  мигающим маркером; экспорт в точечный слой `memory:` с возможностью
  сохранить в GeoPackage; оверлей находок на карте (цвет — по классу
  и исправимости);
* **исправления**: «Исправить» на одной ошибке и «Исправить все
  (безопасные)» для DUP_NODE, T_JUNCTION, NEAR_NODE (слив кластера в
  центроид — только если все затронутые рёбра короче 2× допуска или
  коллинеарны продолжению) и GAP («приклеить» щель к соседу с самой
  длинной общей границей); INVALID — опциональный makeValid с
  подтверждением и площадями «до/после»; OVERLAP — обрезать меньший
  или больший полигон; SPIKE — удалить вершину во всех полигонах,
  где она есть;
* **через валидатор, атомарно, одной отменой**: пачка исправлений —
  это ChangeSet, который прогоняется через валидатор этапа 1 ДО
  записи (блокирующее нарушение отказывает всей пачке — слой битово
  цел), пишется одной командой на слой и откатывается одним Ctrl+Z;
  порог «шва» для пачек NEAR/SPIKE ослабляется ровно на
  геометрическую границу неизбежного клина (сдвиг × длина ребра /
  площадь иглы) — настоящие щели по-прежнему блокируются; если щель
  уже закрыта другими исправлениями пачки, клейка честно отказывается;
* **контроль площади**: если пачка безопасных исправлений меняет
  суммарную площадь слоя больше порога (0,001 % по умолчанию,
  настройка) — пачка отказывается целиком;
* **производительность**: весь слой из 10 000 полигонов проверяется
  за секунды в фоне (приёмка ТЗ — <= 60 с), без замораживания
  интерфейса; пороги проверок (GAP_MAX_AREA, NEAR_NODE_TOL,
  SLIVER_RATIO) — в настройках, группа «Аудит слоя».

### Что нового в 1.10.0

**Этап 4 ТЗ: правка нескольких слоёв одной операцией.** Принцип
«меняется только редактируемый слой» меняется на «меняются слои в
режиме правки, разрешённые в настройках»:

* **участники операции** — все полигональные слои в правке, у которых
  есть узел в той же точке или ребро, проходящее через неё; режим
  «все слои в правке» (по умолчанию) / «только активный слой»;
  чёрный список слоёв в настройках («Слои, которые операции плагина
  НЕ двигают»);
* **разные СК** — единая точка карты преобразуется в СК каждого слоя;
  запись — обратным преобразованием от единой точки (без накопления
  дрейфа), допуск совмещения узлов пропорционален единице СК слоя
  (для градусных — ~0,11 м на земле);
* **атомарность (Committer)** — beginEditCommand на каждом затронутом
  слое; сбой записи в ЛЮБОЙ слой — destroyEditCommand на ВСЕХ:
  частичной записи нет ни в одном слое (слои не рассинхронизируются);
* **общая отмена (OperationLog)** — кнопка «Отменить правку» и Ctrl+Z
  откатывают операцию на ВСЕХ затронутых слоях в порядке, обратном
  записи; если после операции слой правил вручную — отмена отказывается
  с объяснением;
* **транзакционные группы** — оба слоя в одном GeoPackage с режимом
  транзакций QGIS: плагин определяет группу и откатывает операцию
  ОДНИМ undo() группового стека (без двойной отмены);
* **превью** — при захвате узла показываются ленты всех задетых слоёв
  (цвет по слою) и подпись «изменятся слои: …» в строке состояния;
* **перехлёсты со слоями вне правки** — новая per-layer настройка
  «отсекать / спрашивать / не трогать» (спрашивающий диалог — при
  перехлёсте с отмеченным слоем); слои-участники операции не являются
  эталонами отсечения друг друга;
* +32 офлайн-проверки (секция 34), приёмка — `tests/qgis/test_multi_layer.py`
  (4 пункта приёмки ТЗ, включая тест transaction groups на GeoPackage).

### Что нового в 1.9.0

**Этап 3 ТЗ: индекс топологии (TopologyIndex).** Операции перестают
зависеть от запросов getFeatures: узлы, рёбра и соседи ищутся по
ленивому плиточному индексу:

* **мгновенный поиск** — первая операция в новой области строит плитку
  (размер — видимый экстент × 2, настраивается; бюджет сборки 0,4 с —
  при превышении запросы по этой плитке честно идут к слою напрямую),
  повторные — мгновенны; на слоях с десятками тысяч полигонов сетка
  дробится по плотности (порядка 1000 фич на плитку) с мельчанием при
  провале бюджета (до 5 раз); на слое из 10 000 полигонов — в пределах
  приёмки ТЗ (0,5 с первой / 50 мс повторных);
* **правки без пересборки** — правки в режиме редактирования
  (geometryChanged/featureAdded/featureDeleted/committed*) инвалидируются
  хирургически: перерегистрируется только затронутая фича;
* **откат и штатная отмена QGIS** — afterRollBack не сообщает фичи,
  поэтому инвалидируются целиком плитки bbox последней операции
  (журнал операций плагина); без сведений — полная пересборка;
  undo/redo обновляют индекс по тем же сигналам;
* **API ядра** — `nodes_at` (сетка узлов с ячейкой match_eps и проверкой
  соседних ячеек), `edges_near` (QgsSpatialIndex по bbox + повторная
  проверка сегментов), `features_touching`, `neighbors` (BFS по общей
  вершине), `bbox_features`, `snapshot_geometry` (кэш norm_polys);
* **лимит соседей 500 → 5000** (`MAX_OVERLAP_NEIGHBORS`, настраивается)
  с явным сообщением при превышении (в том числе в режиме перехлёстов
  «оставить» — без соседей валидатор пропустил бы потерю общих узлов и
  новые щели);
* **целостность** — `check_integrity()` сравнивает индекс с полной
  пересборкой (в тестах — после цепочек «правка → отмена → повтор →
  rollback»); отладочный режим TOPOPOLEDIT_INDEX_DEBUG=1;
* настройка «индекс включён» (по умолчанию включён; выключение возвращает
  прежнее поведение прямых запросов), фоновая сборка через QgsTask —
  задел под пакетный аудит этапа 5;
* +35 офлайн-проверок (секция 33), приёмка — `tests/qgis/test_topology_index.py`.

### Что нового в 1.8.0

**Этап 2 ТЗ: T-примыкания и автовставка вершин.** Инвариант И4 закрыт:

* **залатывание до записи** — перемещаемый узел или конец ребра, лежащий
  на ребре соседа без вершины, вставляется в это ребро (`insert_vertex_topo`)
  и уезжает вместе с узлом: сосед следует за правкой, щель не возникает;
* **залатывание после записи** — узел, прилипший к ребру своего слоя,
  получает в этом ребре вершину в той же операции (`t_inserted` в отчёте);
* **вершины-пассажиры** — чужая T-вершина на перемещаемом ребре
  переезжает проекцией на новое ребро, а не остаётся висеть на старом;
* правило валидатора `NoTJunction` (этап 2, п. 5): узел, оставшийся на
  чужом ребре без вершины, — предупреждение (не блокирует);
* опция «скользить по соседнему ребру» (по умолчанию включена): конец
  перемещаемого ребра, лежащий на ребре соседа, двигается вдоль него;
* превью: прилипание к ребру чужого слоя — жёлтое предупреждение
  «в слое X нет узла» в строке состояния;
* предупреждения валидатора после записи — отдельным сообщением;
* работает для дыр (внутренних колец) и частей мультиполигонов;
* новые функции ядра: `find_t_edges`, `chain_riders`, `slide_delta`
  (+24 офлайн-проверки), QGIS-тесты приёмки — `tests/qgis/test_t_junction.py`,
  маркер xfail И4 снят.

### Что нового в 1.7.0

**Этап 1 ТЗ: валидатор и блокировка самопересечений.** Конвейер
операции — «план → валидация → запись»:

* makeValid больше не чинит геометрию молча: перемещение, создающее
  самопересечение в любом затронутом полигоне, блокируется (слой битово
  не изменяется), на панели сообщений — кнопка «Показать место»;
* правила: валидность GEOS, шипы, перехлёсты, новые щели (швы-стыки
  игнорируются), сохранение общих узлов; пороги — в QgsSettings;
* превью при перетаскивании: красные маркеры нарушений, заливка щелей,
  причина в строке состояния, запрещающий курсор;
* авторемонт makeValid — настройка с диалогом, по умолчанию выключена;
* чистое ядро `topopolyedit/core/validator.py` без qgis.gui.

### Что нового в 1.6.3

Влиты кандидат-фиксы (статический анализ команды по данным), после
ревью и тестирования:

* **Пул резиновых лент.** Перетаскивание раньше добавляло в сцену холста
  новые `QgsRubberBand` каждый раз — после сотен перетаскиваний они
  накапливались и тормозили QGIS. Теперь ленты переиспользуются, число
  объектов сцены стабильно.
* **Промежуточные вершины общей границы.** При перемещении ребра,
  разделяемого полигонами с разной сегментацией, промежуточные
  коллинеарные вершины на этой границе двигаются вместе с ребром — но
  только если смежное ребро кольца лежит на перемещаемой цепочке
  (посторонняя вершина дыры или соседнего полигона на той же прямой
  не сдвинется).
* **Откат вместо тихого пропуска.** Если при отсечении перемещаемый
  полигон поглощён соседями целиком, поглощён сосед, произошёл сбой
  `difference`/`makeValid`/записи геометрии или результат распался на
  мультигеометрию, которую слой не допускает, — отменяется ВСЯ операция
  (`destroyEditCommand`) с явным сообщением, а не «частично применяется».
* **Лимит соседей.** Соседей того же слоя в области больше 500 —
  операция отменяется целиком: раньше молча выполнялась «частичная
  проверка» с риском неполного отсечения.
* **Лимит эталонов отсечения.** Эталонов в экстенте слишком много —
  отмена с просьбой приблизить масштаб (раньше — предупреждение и
  частичное отсечение).
* **Лимиты аудита внутри одного фича.** Один полигон с >15 000 вершин
  мог обойти лимиты сбора; теперь сбор прерывается по лимитам вершин и
  сегментов с подсказкой «Приблизьте масштаб», превышение числа фич
  помечает результат неполным.
* **Сравнение CRS — объектами.** Два пользовательских CRS с пустым
  authid считались одинаковыми (слой шёл без пересчёта координат);
  теперь полное `crs() == crs()`.
* Тексты ошибок переведены на русский; кнопка «Отменить правку»
  (1.6.2) работает как прежде. Офлайн-тесты: секции 28/30 обновлены и
  расширены (+7 проверок, 218 всего).

### Что нового в 1.6.2

* **Кнопка «Отменить правку»** на панели модуля и **Ctrl+Z** в окне
  карты: последняя операция плагина (перемещение узлов/ребра вместе
  с автоотсечением, вставка узла) откатывается целиком. Работает,
  даже если редактируемый слой не активен: штатная отмена QGIS
  привязана к активному слою, а модуль при нескольких слоях в правке
  выбирает слой под курсором — из-за этого штатная отмена с модулем
  часто оставалась серой. Плагин сам помнит последний изменённый слой
  и ищет цель отката: слой последней правки плагина → активный слой →
  любой слой в правке с непустым стеком отмены. Офлайн-тесты:
  секция 29 (+18 проверок, 211 всего) — выбор цели, устойчивость к
  удалённым слоям, запоминание слоя ядром после move_vertex /
  add_vertex_on_edge.
