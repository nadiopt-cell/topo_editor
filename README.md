# topopolyedit — плагин QGIS для топологического редактирования полигонов

Модуль для QGIS 3.10+ (LTR 3.34/3.40+, Qt5/Qt6). Перемещайте узлы — и смежные
полигоны едут вместе с ними, прилипайте к любым включённым слоям, вставляйте
узлы на общие рёбра; перехлесты отсекаются автоматически.

**Главный принцип: изменяется ТОЛЬКО редактируемый слой.** Остальные слои —
только эталоны для прилипанию и отсечения.

## Возможности

- **Перемещение общих узлов** — один узел двигается сразу во всех полигонах
  редактируемого слоя, где он есть.
- **Прилипание** — к узлам и рёбрам всех включённых (отмеченных в легенде)
  слоёв в экстенте карты; радиус 10 px; приоритет: узел > ребро.
- **Автоотсечение перехлестов** — `difference` по эталонным полигонам
  включённых слоёв при отпускании кнопки.
- **Вставка узла на ребро** — во все полигоны слоя с этим ребром,
  включая T-образные примыкания (защита от «шипов» и дубликатов узлов).
- **Единая отмена** — каждая операция = одна команда Ctrl+Z.

## Структура репозитория

```
topopolyedit/      исходники плагина (то, что пакуется в ZIP)
├── metadata.txt           метаданные модуля
├── plugin.py              тулбар, меню, действия
├── topo_move_tool.py      инструмент перемещения узлов
├── topo_add_vertex_tool.py инструмент вставки узла на ребро
├── topo_editor.py         перемещение узла + автоотсечение, вставка
├── snapping_engine.py     прилипание ко всем включённым слоям
├── geo_utils.py           топологическая математика (2D)
├── utils.py               выбор редактируемого слоя, допуски
└── icons/                 SVG-иконки
tests/test_geo_utils.py офлайн-тесты геометрического ядра (без запуска QGIS)
test_data/             тестовые слои (соприкасающиеся полигоны A, B, C)
tools/make_zip.py      сборка устанавливаемого ZIP в dist/
```

## Установка в QGIS

1. Соберите архив (или возьмите готовый из релиза):
   ```
   python tools/make_zip.py        # -> dist/topopolyedit.zip
   ```
2. QGIS: **Модули → Управление модулями → Установить из ZIP** → `dist/topopolyedit.zip`.
3. Включите модуль **TopoPolyEdit**. Появится панель «Топологическое редактирование»
   и пункты в меню **Вектор**.

## Быстрый старт

1. Загрузите полигональный слой (например, `test_data/topopolyedit_test_data.geojson`)
   и включите редактирование.
2. Кнопка **«Топологическое перемещение узлов»**: наведите на узел (зелёный
   квадрат), зажмите ЛКМ, тяните — оранжевые ленты показывают все полигоны,
   которые поедут вместе с узлом. Отпустите — прилипание + отсечение.
3. Кнопка **«Добавить узел на ребре»**: ребро подсветится оранжевым, клик —
   узел вставлен во все смежные полигоны.
4. **Esc** — отмена перетаскивания / выход из инструмента.

Проверка на тестовых данных: узел (2, 4) общий для полигонов A, B, C —
при перетаскивании изменятся все три; ребро x=2 общее для A и B.

Подробности (алгоритмы, ограничения) — в [topopolyedit/README.md](topopolyedit/README.md).
